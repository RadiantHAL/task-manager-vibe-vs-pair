| `// React TypeScript: Search input component for Task Manager with debounced onChange and clear button` | `const SearchInput = ({ value, onChange }: { value: string; onChange: (v: string) => void }) => (<input type="text" placeholder="Search tasks..." value={value} onChange={(e) => onChange(e.target.value)} />)` | Modified | Modified — added an accessible `aria-label`, embedded search magnifying SVG icon, and an inline escape-key clear handler to improve keyboard accessibility. |
| `// Filter task array in React by both searchQuery (case-insensitive substring) and currentFilter status ('all' \| 'active' \| 'completed')` | `const filteredTasks = tasks.filter(task => (currentFilter === 'all' \|\| (currentFilter === 'active' ? !task.completed : task.completed)) && task.title.includes(searchQuery))` | Rejected | Rejected — `task.title.includes(searchQuery)` is strictly case-sensitive and throws a TypeError if `task.title` is undefined; replaced with `task.title.toLowerCase().includes(searchQuery.trim().toLowerCase())`. |
| `// Render empty state UI in React when filteredTasks is empty due to active searchQuery vs general empty list` | `{filteredTasks.length === 0 && <p className="empty-msg">No tasks match "{searchQuery}". <button onClick={() => setSearchQuery('')}>Clear search</button></p>}` | Accepted | Accepted — accurately detects the query-specific zero-match state and provides a direct one-click action to reset the search filter without reloading. |
